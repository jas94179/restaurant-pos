# Logos

The real app icon files from the galla app (`app/assets/`). Use them exactly; never redraw or recolour the coin.

- `icon.png`: the app icon, 1024 × 1024. Gold coin with the rupee sign over a cash-box slot, on curry-leaf green. Use for app stores, favicons on light pages, and social profile pictures.
- `android-icon-foreground.png`: the coin and slot on transparent, for Android adaptive icons and for placing the mark on `bg-brand`.
- `android-icon-monochrome.png`: one-colour version for Android themed icons; the system tints it.
- `splash-icon.png`: the mark shown on the launch screen over `bg-brand`.
- `favicon.png`: small favicon for web pages.
